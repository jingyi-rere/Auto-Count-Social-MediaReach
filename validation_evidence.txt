7. MANUAL / REAL-DATA DEMO
════════════════════════════════════════════════════
The live system runs as a watcher daemon (watcher.py) that polls the Lark
base every 3 minutes. On each tick it:

  1. Calls lark_reader.get_new_rows() to fetch rows that have a URL but
     are missing either the posted-date or view-count.
  2. Routes each URL to the correct extractor:
       YouTube / TikTok  -> yt-dlp (metadata-only, no browser needed)
       Instagram         -> Firefox + Claude Vision (reel screenshot +
                           grid screenshot to get accurate view count)
       RedNote (xiao hong shu)  -> Firefox + Claude Vision (single screenshot)
  3. Writes the extracted date, caption, content_type ("nei rong-ri chang"), and
     view count back to the Lark base via a single PATCH call per row.

Four platforms are fully supported and have been tested against live URLs
in development. The Firefox profile is persisted at
~/.cache/auto-count/firefox-profile so Instagram sessions survive restarts.

Recent live test (prior to this submission): watcher processed 6 rows in
one cycle — 3 YouTube, 2 Instagram, 1 RedNote — all wrote successfully to
Lark; run time approx. 47 s (dominated by two Firefox Vision calls at ~15 s each).
